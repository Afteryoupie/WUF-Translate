# WUF Translate｜網頁與 YouTube 雙語翻譯

WUF Translate 是 Chrome／Edge 的瀏覽器擴充功能，幫你把外文網頁與 YouTube 字幕翻成繁體中文，並保留原文對照。你可以使用 Google 翻譯、線上 AI，或搭配 [WUF Watchdog](https://github.com/Afteryoupie/WUF-Watchdog#readme)，讓自己的電腦執行翻譯。

不需要先學會 LLM 的原理。第一次先選一種翻譯方式，確認能看到譯文，再考慮自訂模型與 Laya。**一般使用者取得已建置的擴充功能套件後，不需要安裝 Node.js、Python 或編譯工具。**

> **目前安裝狀態（2026-10-25）：尚未提供已建置的擴充功能 ZIP，也尚未提供正式商店安裝連結。**
> 安裝附件未來會放在 [Releases 發布頁](https://github.com/Afteryoupie/WUF-Translate/releases)。GitHub 的 **Code → Download ZIP** 與 **Source code ZIP** 都是原始碼，不能直接載入瀏覽器。
>
> 現階段需由維護者或熟悉電腦操作的人依[開發者建置文件](docs/BUILD.md)製作套件，再依本頁安裝。Node.js 是製作套件的工具，不是一般使用者的日常使用需求。

## 先了解要安裝哪些東西

| 名稱 | 白話說明 | 是否需要 |
| --- | --- | --- |
| WUF Translate | 瀏覽器裡的翻譯按鈕，讀取原文並顯示譯文 | 需要 |
| 翻譯服務 | 實際把文字翻成中文的服務 | 下方三種方式選一種即可 |
| WUF Watchdog | 在自己的電腦管理及啟動 AI 模型的另一個程式 | 使用 Watchdog 本機翻譯時需要 |
| Apple／GGUF 模型 | 本機 AI 實際使用的模型 | 依 Watchdog 的系統與模式準備 |
| Laya | 依影片主題協助選擇部分詞義的另一個模型 | 選用，第一次先跳過 |
| Node.js／npm | 把原始碼製作成擴充功能套件的工具 | 一般使用者不需要；自行建置才需要 |

**WUF Translate 與 Watchdog 要分別安裝。** 擴充功能不會替你安裝 Watchdog、下載模型，或建立線上服務帳號。Watchdog 也不會替你安裝擴充功能。

本頁的瀏覽器安裝流程適用於桌面版 Chrome／Edge，包含 Windows 與 macOS；不包含 Safari、Firefox 或手機瀏覽器的安裝流程。YouTube 翻譯需要影片本身有人工字幕或自動字幕，WUF 不會直接聽聲音產生逐字稿。

## 安裝順序

1. [選擇一種翻譯方式](#1-選擇翻譯方式)。若要用 Watchdog，先完成它的安裝與模型就緒檢查。
2. [載入 WUF Translate 擴充功能](#2-載入瀏覽器擴充功能)。
3. [設定翻譯服務，確認連線成功](#3-設定翻譯服務確認能運作)。
4. [先翻譯一篇網頁，再測試 YouTube 字幕](#4-第一次翻譯)。

沒有本機模型也能使用 Google 翻譯；不需要為了開始翻譯先設定 Laya。

## 1. 選擇翻譯方式

| 方式 | 要準備什麼 | 文字送到哪裡 |
| --- | --- | --- |
| Google 翻譯 | 網路連線，不需要 API 金鑰 | Google 翻譯服務 |
| Watchdog 本機翻譯 | 已安裝並啟動的 Watchdog，以及可用模型 | 自己電腦上的 Watchdog，再由所選後端處理 |
| 線上自訂模型 | 服務商的 API 網址、API 金鑰與模型名稱 | 你設定的線上服務商 |

API 可以理解成「讓擴充功能請服務幫忙翻譯的入口」，API 金鑰是入口的通行證。聊天網站的會員訂閱不一定包含 API 使用額度。

### 使用 Watchdog 的人先做這一步

依 [Watchdog 安裝指南](https://github.com/Afteryoupie/WUF-Watchdog#readme)完成對應系統的準備。本頁不重複安裝指令，以該指南的版本需求與發布說明為準。

- **macOS**：該指南目前的預設流程使用 Apple Foundation Models，透過 macOS 27 的系統工具連接本機 AI；先確認支援 Apple Intelligence、系統模型已就緒。這個流程不用另外下載 GGUF 或 llama.cpp。
- **Windows**：依該指南準備 GGUF 模型與 llama.cpp 執行工具，首次先確認小模型能載入並回應。
- **兩種系統都要確認**：啟動 Watchdog，在瀏覽器開啟 `http://127.0.0.1:8080`，選擇模型並等到「準備就緒」，再回來設定 WUF Translate。

「看得到 Watchdog 控制台」只代表管理程式已啟動；接下來還要測試模型是否能產生文字。Watchdog 的安裝包也有自己的發布狀態，請先確認其 Releases 是否提供完整套件。

## 2. 載入瀏覽器擴充功能

以下適用於已取得維護者提供的**已建置套件**；目前公開附件尚未提供。自行建置的人請先完成[建置文件](docs/BUILD.md)，再載入產出的 `dist/wuf`。

1. 從 [Releases](https://github.com/Afteryoupie/WUF-Translate/releases)取得發布說明標示的擴充功能安裝 ZIP，解壓縮到固定位置。不要將 Source code ZIP 當成安裝包。
2. 找到解壓縮後直接包含 **`manifest.json`** 的資料夾。若看見的是 `package.json`、`wuf-src`，那是原始碼目錄，還不是可載入的擴充功能。
3. 開啟 Chrome，在網址列輸入 `chrome://extensions`；Edge 則輸入 `edge://extensions`。
4. 開啟「開發人員模式」，按「載入未封裝項目」或「載入解壓縮」，選擇第 2 步的資料夾。
5. 確認清單中出現 **WUF Translate**，再到瀏覽器工具列的「擴充功能」選單將它釘選。

手動載入後，請保留解壓縮的資料夾，瀏覽器仍會從這個位置讀取檔案。尚未設定翻譯服務前，看到 WUF 圖示不代表模型已能運作。

正式上架商店後，會在這裡提供安裝連結；屆時可直接按「新增」，不需要開發人員模式。**目前沒有商店安裝連結，也不會因為載入擴充功能就自動安裝 Watchdog。**

## 3. 設定翻譯服務，確認能運作

按工具列的 WUF 圖示，再按齒輪開啟設定。設定會自動儲存，不需要另外按儲存。

**網頁與 YouTube 的翻譯引擎分開設定。** 想同時翻譯兩者，就要分別到「網頁翻譯」與「YouTube 字幕翻譯」選好引擎。目標語言填 `zh-TW`，代表台灣繁體中文。

### A. 沒有本機服務：Google 翻譯

1. 到「網頁翻譯」，將引擎改為 **Google 翻譯（免費備援）**。
2. 到「YouTube 字幕翻譯」，也選同一個引擎。
3. 在字幕頁下方的「字幕情境與決策模型」，將來源改為 **不使用決策模型（保留本地字幕保護）**。
4. 不需要填模型名稱或 API 金鑰，接著依第 4 節翻譯一篇網頁確認能用。

擴充功能初始設定使用本機服務，因此沒有安裝 Watchdog 的人要先切換引擎。「免費備援」是可自行選用的選項，不代表遇到錯誤都會自動改用 Google；它仍需要網路，也可能遇到服務限制。

### B. 已準備好 Watchdog：本機翻譯

先確認 Watchdog 控制台的模型已「準備就緒」，再到「本機自訂模型」填寫：

| 欄位 | 使用 Watchdog 時如何填寫 |
| --- | --- |
| API 網址 | `http://127.0.0.1:8080/v1`，注意最後有 `/v1` |
| API 金鑰 | 使用 Watchdog 預設本機設定時留空 |
| 模型名稱 | 按「重新讀取模型清單」後選擇，或按「回到服務預設模型」 |
| 專屬模型覆寫 | 在網頁／字幕設定中先留空，沿用所選模型 |

1. 按 **「測試模型運作」**，等到成功回應。這才代表瀏覽器到本機模型的完整連線已打通。
2. 到「網頁翻譯」選擇 **本地模型（Watchdog／Ollama）**。
3. 若要翻譯影片，再到「YouTube 字幕翻譯」選相同引擎；第一次先將決策模型設為「不使用決策模型」。

`127.0.0.1` 指的是「這台電腦」。控制台網址是 `http://127.0.0.1:8080`，擴充功能的 API 網址則是 `http://127.0.0.1:8080/v1`。不要把 Watchdog 內部模型服務的 8081／8082 連接埠填進這裡。

已有其他 OpenAI 相容服務的人，也可填該服務提供的 API 網址與模型名稱，並手動保持服務執行；它不會因此具備 Watchdog 的自動管理功能。

### C. 使用線上自訂模型

1. 向服務商取得 **API 網址、API 金鑰、模型名稱（Model ID）**。需要 OpenAI 相容的聊天介面；只有聊天網站網址不能直接使用。
2. 到「線上自訂模型」填入三項資料。例如預設 OpenRouter 網址為 `https://openrouter.ai/api/v1`，模型名稱要填服務商提供的完整 ID。
3. 按 **「測試模型運作」**；測試也會送出請求，可能使用服務額度。
4. 到「網頁翻譯」與／或「YouTube 字幕翻譯」，將引擎改為 **線上自訂（OpenAI 相容／OpenRouter）**。第一次先關閉字幕決策模型。

溫度、思考等級、額外 JSON、並行數與 Prompt（給 AI 的文字指示），第一次先維持預設。字幕與文章的 Prompt 分開設定。

## 4. 第一次翻譯

### 先翻譯一篇網頁

1. 開啟一般英文文章網頁。
2. 按 WUF 圖示，再按「翻譯網頁」。
3. 等到文章出現譯文；選「雙語對照」保留原文，或選「僅顯示譯文」。
4. 要恢復原文時，按「顯示原文」。

也可用 `Alt+S` 切換網頁翻譯；macOS 的 Alt 就是 Option。瀏覽器設定頁與擴充功能商店等受保護頁面不能注入翻譯，請用一般網站測試。

### 再測試 YouTube 字幕

1. 確認「YouTube 字幕翻譯」頁的引擎與目標語言已設定。
2. 開啟一支有英文字幕的影片，在播放器開啟 **CC**，選英文或英文自動產生字幕。
3. 按 WUF 圖示，開啟「YouTube 字幕」。
4. 重新整理影片分頁並播放，讓 WUF 取得字幕資料；先暫停影片，等第一批翻譯完成。
5. 看到影片上的雙語字幕後再繼續播放；可在 WUF 面板調整字幕大小。

第一批字幕可能需要等待模型喚醒與翻譯。電腦能載入模型，不代表一定能跟上影片速度；來源字幕的辨識錯誤也會影響譯文。

## 日常使用與本機休眠

- **自動翻譯指定網站**：將目前網站加入自動翻譯清單。
- **跨分頁延續翻譯**：在其他分頁延續網頁翻譯狀態。
- **簡繁自動互轉（OpenCC）**：轉換中文字形與部分用詞，不負責把英文翻成中文。
- **字幕分批參數**：預設一次準備 30 秒字幕，在快用完前 10 秒準備下一批；先維持預設，批次更大不代表更快。

Watchdog 預設閒置約 3 分鐘會讓模型休眠，服務仍在時可由下一筆請求重新載入。若整個 Watchdog 已退出，要先手動開啟程式，或事先依 [Watchdog 指南](https://github.com/Afteryoupie/WUF-Watchdog#readme)註冊 Native Host（瀏覽器連接功能），才能從瀏覽器喚醒。**註冊連接功能與設定登入自動啟動是兩回事。**

目前自動喚醒使用的 WUF Translate 識別碼為 `iecdpfnjngfljdlpookikhidlbfbmidb`。若你自行修改擴充功能身分，或日後商店版使用不同識別碼，需要配合更新 Watchdog 註冊；仍可先手動啟動 Watchdog，以 API 翻譯。

## Laya 決策模型：基本翻譯成功後再設定

翻譯模型負責產生譯文，Laya 負責輔助判斷影片主題。兩者分開運作，普通翻譯模型或 GGUF 檔不能直接替代 Laya。

| 模式 | 功能與條件 |
| --- | --- |
| 不使用決策模型 | 不加主題詞義提示；仍保留本地斷句、音效標記清理、格式檢查與一次錯誤重試，不需要額外決策服務 |
| 本機 Laya | 依影片標題與開頭字幕選擇主題，為中文 AI 翻譯提供少量詞義提示；需要另外準備 Laya 服務 |
| 自訂決策模型 | 由指定模型判斷字幕斷句、過濾與輸出格式，額外請求可能增加等待時間 |

若要用 Laya，先依 [Watchdog 的 Laya 設定說明](https://github.com/Afteryoupie/WUF-Watchdog#laya-決策模型)準備完整模型與獨立 Python 環境，在控制台確認決策模型就緒，再到 WUF 設定 →「YouTube 字幕翻譯」→「字幕情境與決策模型」選「本機 Laya」。端點預設為 `http://127.0.0.1:8080/v1/systemone`。**只有選用這項功能才需另外準備 Laya 的 Python 環境。**

Laya 目前在攝影、汽車、園藝領域提供人工整理的詞義提示，例如攝影影片中的 `body` 提示為「機身」。每片的主題結果會暫存，分類時以兩種選項順序交叉確認；每句只加入用得到的詞義，最多四組，不再逐句呼叫 Laya。Google 翻譯不使用這些 AI 提示。

Laya 不看影片畫面、不檢查整句翻譯是否正確；判斷不明確時不加提示。真實字幕小樣本測試發現部分詞義改善，但不保證所有影片更準確或完全即時，詳見[目前的最小提示測試報告](docs/laya-subtitle-context.md)。[早期報告](docs/laya-youtube-evaluation.md)記錄改版前流程，不能當作目前版本的效果。

## 安裝與翻譯遇到問題

| 情況 | 處理方式 |
| --- | --- |
| Releases 沒有安裝附件 | 目前尚未發布套件；等待維護者提供，或請開發者依[建置文件](docs/BUILD.md)製作。Source code ZIP 不能直接載入 |
| 載入時找不到 manifest | 先解壓縮套件，選直接包含 `manifest.json` 的資料夾；自行建置者選 `dist/wuf` |
| 沒安裝 Watchdog，畫面一直顯示本機離線 | 將網頁與 YouTube 引擎分別改成 Google 翻譯，字幕決策模型選「不使用」 |
| Watchdog 控制台開不了 | 先手動啟動 Watchdog；依其指南處理安裝、系統條件與程式路徑，不必先重裝擴充功能 |
| 控制台能開，卻不能翻譯 | 確認模型「準備就緒」、API 網址最後有 `/v1`，再按「測試模型運作」；控制台可開不代表模型可用 |
| 手動開啟 Watchdog 能翻譯，但無法從瀏覽器喚醒 | 確認 Native Host 註冊、程式位置與擴充功能識別碼，註冊後重新開啟瀏覽器 |
| 顯示沒有 Laya 或決策環境 | 第一次先選「不使用決策模型」，不影響基本翻譯 |
| 線上服務回傳 401／403 | 檢查 API 金鑰、模型名稱及服務存取權限 |
| 回傳 429 | 通常是服務限流或額度問題；稍後重試並查看服務商限制 |
| YouTube 沒有譯文 | 確認影片有字幕、CC 已開、字幕引擎已設定、WUF「YouTube 字幕」已開，再重新整理並播放 |
| 字幕跟不上 | 暫停等第一批完成；比較回應較快的服務，先關閉自訂決策模型，不要直接加大批次 |
| 改了設定仍看到舊譯文 | 在 WUF 面板按「清除快取」並確認，再重新整理分頁 |
| 譯文怪異或漏字 | 先查看來源字幕是否有辨識錯誤，再比較其他翻譯服務；Laya 不能修正所有翻譯錯誤 |

回報問題可到 [Issues](https://github.com/Afteryoupie/WUF-Translate/issues)，提供系統、瀏覽器版本、使用引擎、錯誤文字與重現步驟。不要附上 API 金鑰。

## 資料會送到哪裡？

- **Google 翻譯**：待翻譯文字送到 Google 翻譯端點。
- **線上自訂模型**：文字與翻譯指示送到你設定的服務商，費用與資料處理由該服務決定。
- **本機模型**：請求送到設定的地址。Watchdog 的本機 Apple／GGUF 流程在電腦上處理；若另設會轉送的後端，仍以該後端為準。下載程式、模型及來源網頁需要網路。
- **Laya**：影片標題與開頭字幕樣本送到設定的決策端點，預設為本機 Watchdog。
- **設定與金鑰**：設定保存在瀏覽器儲存空間，API 金鑰另存本機區域，不包含在設定匯出中。匯出檔仍可能含服務網址及個人偏好，分享前先查看。

WUF 需要網站存取權才能讀取與翻譯網頁。可在瀏覽器的擴充功能詳細資料中限制網站存取權；限制後，相關網站的翻譯也會受影響。

## 更新、備份與移除

1. 在設定 →「備份與重設」匯出設定。移除或換電腦前先備份；匯入後需重新填 API 金鑰。
2. 手動載入者取得新版已建置套件後，更新原套件資料夾；若更換位置，需重新選擇載入位置。
3. 到擴充功能管理頁按 WUF 的「重新載入」，再重新整理已開啟的網頁與 YouTube 分頁。自行建置者要先重新建置；未來商店版則依瀏覽器機制更新。

移除時，在瀏覽器擴充功能管理頁按「移除」，再刪除不需要的套件資料夾。**移除 WUF Translate 不會移除 Watchdog、模型或 Native Host 註冊**；要一併移除時，另依 [Watchdog 移除指南](https://github.com/Afteryoupie/WUF-Watchdog#移除)操作。

本專案是 TypeScript／Manifest V3 擴充功能。Watchdog 為獨立專案，透過 HTTP API 與原生瀏覽器主機連接。不要提交模型、個人路徑、API 金鑰或診斷輸出；已安裝版本的公開識別金鑰應保持一致。
